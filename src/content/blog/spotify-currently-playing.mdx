<br />

Spotify APIで現在再生中の曲名とアーティスト名を取得する方法をまとめます。主な流れはIDからrefresh tokenを取得し、そのトークンを使ってSpotify Web APIを呼び出すことです。

# 処理の流れ

1. Developer DashboardでSpotifyアプリを作成し、再生情報を読む権限をユーザーから得る
2. 認証コードをrefresh tokenに交換する
3. refresh tokenからaccess tokenを取得する
4. access tokenで現在再生中の曲を取得する

<br />
Client Secretとrefresh tokenを扱う処理は、ブラウザーではなくサーバー側で実行します。

# Spotifyアプリの準備

<a href='https://developer.spotify.com/dashboard' className='text-blue-600 hover:underline'>Spotify Developer Dashboard↗</a>でアプリを作成します。アプリのRedirect URIには、認可後の戻り先として必要なURIを登録します。

```text
http://127.0.0.1:3000/callback
```

現在再生中の曲を取得するために必要なAPIのscopeは`user-read-currently-playing`です。

# Refresh tokenの取得

最初にユーザーの認可を受けてauthorization codeを取得し、それをrefresh tokenに交換します。以下はPowerShellでの例です。

## Authorization codeを取得する

```powershell
$CLIENT_ID = "SpotifyのClient ID"
$REDIRECT_URI = "http://127.0.0.1:3000/callback"
$SCOPE = "user-read-currently-playing"
$STATE = [guid]::NewGuid().ToString("N")

$authUrl = "https://accounts.spotify.com/authorize" +
  "?client_id=$([uri]::EscapeDataString($CLIENT_ID))" +
  "&response_type=code" +
  "&redirect_uri=$([uri]::EscapeDataString($REDIRECT_URI))" +
  "&scope=$([uri]::EscapeDataString($SCOPE))" +
  "&state=$STATE"

Start-Process $authUrl
```

ブラウザーで許可すると、次のようなURLに移動します。

```text
http://127.0.0.1:3000/callback?code=xxxxx&state=yyyyy
```

ローカルサーバーを起動していなければ接続エラーが表示されますが、URLの取得だけが目的なので問題ありません。

URLの`state`がPowerShellに表示した`$STATE`と一致することを確認し、`code`の値だけを控えます。`code=`や`&state=...`は含めません。

## Authorization codeをトークンに交換する

```powershell
$CLIENT_ID = "SpotifyのClient ID"
$CLIENT_SECRET = "SpotifyのClient Secret"
$REDIRECT_URI = "http://127.0.0.1:3000/callback"
$CODE = "取得したcodeの値"

$basic = [Convert]::ToBase64String(
  [Text.Encoding]::UTF8.GetBytes("${CLIENT_ID}:${CLIENT_SECRET}")
)

$response = Invoke-RestMethod `
  -Method Post `
  -Uri "https://accounts.spotify.com/api/token" `
  -Headers @{ Authorization = "Basic $basic" } `
  -ContentType "application/x-www-form-urlencoded" `
  -Body @{
    grant_type = "authorization_code"
    code = $CODE.Trim()
    redirect_uri = $REDIRECT_URI
  }

$response.refresh_token
```

表示された値を`SPOTIFY_REFRESH_TOKEN`として安全に保存します。authorization codeは一度しか使えないので、失敗した場合は新しいcodeを取得してください。

# 現在再生中の曲を取得する

`GET /v1/me/player/currently-playing`を呼び出します。以下にサンプルのコードを載せておきます。

```ts
type Credentials = {
  clientId: string;
  clientSecret: string;
  refreshToken: string;
  saveRefreshToken: (token: string) => Promise<void>;
};

type NowPlaying = {
  isPlaying: boolean;
  name: string;
  artist: string;
};

const notPlaying: NowPlaying = {
  isPlaying: false,
  name: "",
  artist: "",
};

export async function getCurrentlyPlayingTrack({
  clientId,
  clientSecret,
  refreshToken,
  saveRefreshToken,
}: Credentials): Promise<NowPlaying> {
  const tokenResponse = await fetch("https://accounts.spotify.com/api/token", {
    method: "POST",
    headers: {
      Authorization: `Basic ${btoa(`${clientId}:${clientSecret}`)}`,
      "Content-Type": "application/x-www-form-urlencoded",
    },
    body: new URLSearchParams({
      grant_type: "refresh_token",
      refresh_token: refreshToken,
    }),
  });

  if (!tokenResponse.ok) {
    throw new Error(`Token request failed: ${tokenResponse.status}`);
  }

  const tokenData = (await tokenResponse.json()) as {
    access_token?: string;
    refresh_token?: string;
  };

  if (!tokenData.access_token) {
    throw new Error("Access token was not returned");
  }

  if (tokenData.refresh_token && tokenData.refresh_token !== refreshToken) {
    await saveRefreshToken(tokenData.refresh_token);
  }

  const response = await fetch(
    "https://api.spotify.com/v1/me/player/currently-playing",
    {
      headers: {
        Authorization: `Bearer ${tokenData.access_token}`,
      },
    },
  );

  if (response.status === 204) {
    return notPlaying;
  }

  if (!response.ok) {
    throw new Error(`Currently playing request failed: ${response.status}`);
  }

  const playback = (await response.json()) as {
    is_playing: boolean;
    currently_playing_type: string;
    item: null | {
      name: string;
      artists?: Array<{ name: string }>;
    };
  };

  if (
    !playback.is_playing ||
    playback.currently_playing_type !== "track" ||
    !playback.item?.artists
  ) {
    return notPlaying;
  }

  return {
    isPlaying: true,
    name: playback.item.name,
    artist: playback.item.artists.map((artist) => artist.name).join(", "),
  };
}
```

`saveRefreshToken`には、利用する環境に合わせた安全な保存処理を渡します。Spotifyが更新後のrefresh tokenを返した場合、次回からその値を使えるようにします。Client ID、Client Secret、refresh tokenは、利用するデプロイ環境のSecret管理機能などに登録してください。

この例では、曲を再生しているときに次の形式を返します。

```json
{
  "isPlaying": true,
  "name": "Song name",
  "artist": "Artist name"
}
```

再生情報がないとき、再生を停止しているとき、または取得した項目が曲ではないときは、次の形式を返します。

```json
{
  "isPlaying": false,
  "name": "",
  "artist": ""
}
```

# うまく動かないとき

- `invalid_client`が返る場合は、Client IDとClient Secretの組み合わせを確認します。
- `invalid_grant`がauthorization codeの交換時に返る場合は、codeをすでに使っていないか、認可時と交換時のRedirect URIが一致しているかを確認します。新しいcodeを取得して、すぐに交換してください。
- refresh tokenの更新時に`invalid_grant`が返る場合は、トークンが期限切れか無効になっている可能性があります。もう一度認可フローを行い、新しいrefresh tokenを保存します。<a href='https://developer.spotify.com/documentation/web-api/tutorials/refreshing-tokens' className='text-blue-600 hover:underline'>Spotifyのドキュメント↗</a>によると、Developer Dashboardで登録したアプリのrefresh tokenには6か月の有効期間があり、access tokenの更新では延長されません。

# まとめ

authorization codeをコピーするときにstateが含まれてしまい、うまく動かないことがある（2敗）ので注意して下さい。

認可の最新の情報は<a href='https://developer.spotify.com/documentation/web-api/tutorials/code-flow' className='text-blue-600 hover:underline'>公式のAuthorization Code Flow↗</a>、取得するデータの仕様は<a href='https://developer.spotify.com/documentation/web-api/reference/get-the-users-currently-playing-track' className='text-blue-600 hover:underline'>Get Currently Playing Track↗</a>を参照してください。
