C++の環境構築をしたいだけなのにmingwとllvmを探して落とし，Visual Studio build tool（めっちゃ重い）をインストールして…というフローを踏まされるWindowsに嫌気がさしてきたので，最近はwsl上のUbuntuで開発環境を整えている．
もしかしたらもっとスムーズな方法があるかもしれないが，どちらにせよPowershellを使いたくないので…

いい機会なので，これまでの自分の開発環境，とくに使っていたOSとテキストエディタを振り返ってみた↓

- 2021~2024前半?：Windows, VS Code
- 2024後半~2025前半：Windows + Ubuntu (dual boot), VS CodeかVim
- 2025後半~：Windows + Ubuntu (WSL), WindowsではVS CodeかZed，UbuntuではNeovim + LazyVim


lazyvimはIDE的な使い勝手がかなり良かったのだが，今月に<a href='https://github.com/sinelaw/fresh' className='text-blue-600 hover:underline'>Fresh↗</a>というterminal IDEを見つけて使い始めたところ，かなり良かったので移行することにした．

私はVimの基本コマンドは覚えているものの，「思考の速さでタイプする」必要がない人間（思考がタイプより遅い）なので，FreshのようなマウスフレンドリーかつFile Finderが使えるようなエディタを求めていた．まだ使ったことはないが，LSPやAgent Orchestratorもあるらしい．

neovimよりmicroが好きだったり，ターミナルでVS CodeのようなIDEの操作感を求める人はかなりいい体験ができると思うのでぜひ使ってみて下さい．
